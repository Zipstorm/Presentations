10. Live Fill Checklist

The entire fill experience lives in one checklist. Helix fills what it is confident about, pauses on anything missing or low-confidence, and resumes when the user completes the field on the page.


┌─────────────────────────────────────────┐
│                                         │
│  Filling your application               │
│  Waiting for you                        │
│                                         │
│  ─────────────────────────────────────  │
│                                         │
│  ✓ Name                                 │
│  ✓ Email                                │
│  ✓ Phone                                │
│  ✓ LinkedIn                             │
│  ! Salary expectations                  │
│  ○ Visa sponsorship                     │
│  ○ Why this role?                       │
│  ○ Relevant experience                  │
│  ○ Resume upload                        │
│                                         │
│  ─────────────────────────────────────  │
│                                         │
│  [ Pause filling ]                      │
│                                         │
└─────────────────────────────────────────┘

Flow Sequence

Happy path and edge case navigation between screens.


HAPPY PATH:

  Install extension
       |
  [1. Not Logged In] --sign in--> [3. Idle]
       |                              |
  (or if already signed in)      Navigate to application form
       |                              |
  [2. No Portfolio] --complete-->  [13. Application Form Detected]
                                      |
                                  Click extension
                                      |
                               (first time only)
                                      |
                               [4. First-Use Comparison]
                                      |
                                  "Got it"
                                      |
                               [5. JD Confirmation]
                                  or [6. JD Paste]
                                      |
                               "Tailor my application"
                                      |
                               [7. Tailoring Progress]
                                      |
                               [8. Preview (Collapsed)]
                                  or [9. Preview (Expanded)]
                                      |
                               "Fill Application"
                                      |
                               [10. Live Fill Checklist]
                          (fills ↔ waits ↔ resumes in place)
                                      |
                               [14. Form Filled]
                                  or [15. Generic Fill]
                                      |
                               User reviews + submits
                                      |
                               [11. Post-Fill Confirmation]


ERROR / EDGE PATHS:

  Network error during tailoring --> [12. Error State]
  Multi-page form ----------------> [16. Multi-Page] per-page fill
  JD not found on page -----------> [6. JD Paste Fallback]
